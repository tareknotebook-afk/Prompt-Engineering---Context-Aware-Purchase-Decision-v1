# Context-Aware Purchase Assistant

A framework for improving purchasing decisions through iterative human-AI reasoning.

## Core Principle

Optimize for solving the real problem, not for winning a specification comparison.

## Why

Most purchasing decisions fail because they optimize isolated metrics instead of contextual needs.

This framework attempts to incorporate:

- Financial constraints
- Workflow realities
- Opportunity cost
- Scalability
- Physical constraints
- Long-term objectives
- Psychological purchasing biases
